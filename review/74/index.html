A voice message on its own: Download only in the message's menu

Head 92a67a6fe (PR 495 branch, 2.51.0) · Mac, iPhone and Android, light and dark. Tap a shot to enlarge.

Before → after

  • Before: a sound a bot sent on its own rendered as a plain file card with a visible Download button on the row — on Mac, iPhone and Android alike.
  • After: the same sound renders as the voice-note player — play, the bar, the clock, the file's name under the row — with no Download button. Download lives in the message's menu: right-click or the ⋯ button on the Mac, press and hold on the phones.

What changed

  • iOS, Android and desktop route a standalone playsInChat file through the same player a voice note inside a message uses — no separate file card, no Download button on the row.
  • Download is in the message's menu, after Copy — including the desktop ⋯ menu, which previously skipped it.
  • The desktop e2e checks both menus; the phones' Maestro flow gained a voice-file mode that sends the note without text.
